AI-Assisted Fitts' Law Experiment

Drone Target Selection Simulator — an HCI experiment for measuring the relationship between target distance, target width, and movement time.

Scenario, Innovation, and Application

Scenario

This experiment simulates a drone-monitoring interface in which an operator must quickly select detected targets on the screen. During real-time monitoring, targets may appear at different distances and sizes, which can affect selection speed.

Innovation

The interface adds a target-lock guidance cue: each detected target is highlighted with a pulsing visual ring and a directional guide line from the previous selection point. The cue is designed to support rapid target acquisition without changing the target's actual clickable width.

Application

This design investigates pointing performance in interfaces such as drone control, surveillance systems, and real-time monitoring dashboards, where operators may need to select spatially distributed visual targets under time pressure.

Why this design?

Drone and monitoring interfaces often contain spatially distributed targets with different apparent sizes. Fitts' Law provides a useful model for evaluating how target distance and width affect selection time, while the guidance cue explores a practical interface aid for time-sensitive pointing tasks.
